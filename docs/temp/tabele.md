# Рад са табелама

Табеле можеш да креираш помоћу усправних црта `|` и цртица `-`. Први ред табеле
је увек заглавље које садржи називе колона одвојене усправним цртама. Други ред
раздваја заглавље од осталих редова са подацима и треба да садржи најмање три
цртице у свакој колони. Пре табеле мораш да оставиш један празан ред како би
она била исправно приказана. На пример, овако креирана табела...

``` markdown

| Бр. | Име   | Презиме   |
| --- | ----- | --------- |
| 1   | Петар | Петровић  |
| 2   | Јован | Јовановић |
| 3   | Мира  | Мирић     |
```

...биће приказана овако:

| Бр. | Име   | Презиме   |
| --- | ----- | --------- |
| 1   | Петар | Петровић  |
| 2   | Јован | Јовановић |
| 3   | Мира  | Мирић     |

Ћелије могу да се разликују по ширини и **не мораш** их савршено поравнати
унутар колона - поравнате ћелије естетски лепше изгледају у Markdown документу,
али се рендерују (приказују) исто. Тако ће ова табела...

``` markdown

| Бр. | Име | Презиме |
| --- | --- | --- |
| 1 | Петар | Петровић |
| 2 | Јован | Јовановић |
| 3 | Мира | Мирић |
```

...бити приказана исто као и претходна:

| Бр. | Име | Презиме |
| --- | --- | --- |
| 1 | Петар | Петровић |
| 2 | Јован | Јовановић |
| 3 | Мира | Мирић |

Табела ће се исправно приказати чак иако се изоставе почетне и крајње усправне
црте у редовима испод заглавља...

``` markdown

| Бр. | Име | Презиме |
--- | --- | ---
1 | Петар | Петровић
2 | Јован | Јовановић
3 | Мира | Мирић
```

...што изворни код табеле чини још непрегледнијим.

У табели није неопходно да свака ћелија садржи податак. Ако неки податак
недостаје, одговарајућу ћелију можеш оставити празну. У следећем примеру...

``` markdown

| Име   | Презиме   | Оцена |
| ----- | --------- | ----- |
|       | Петровић  | 5     |
| Јован | Јовановић |       |
| Мира  |           | 4     |
```

...табела ће бити приказана овако:

| Име   | Презиме   | Оцена |
| ----- | --------- | ----- |
|       | Петровић  | 5     |
| Јован | Јовановић |       |
| Мира  |           | 4     |

Као што видиш, ћелије у којима нема података остају празне, али се табела и
даље исправно приказује.

Није неопходно ни да сваки ред садржи исти број елемената као заглавље. Ако ред
садржи мање елемената од броја колона, преостале ћелије ће бити празне. Следећа
табела...

``` markdown

| Име   | Презиме   | Оцена |
| ----- | --------- | ----- |
| Петар | Петровић  | 5     |
| Јован | Јовановић |
| Мира  | Мирић     | 4     |
```

...ће бити приказана овако:

| Име   | Презиме   | Оцена |
| ----- | --------- | ----- |
| Петар | Петровић  | 5     |
| Јован | Јовановић |       |
| Мира  | Мирић     | 4     |

У другом реду изворног кода недостаје податак за колону `Оцена`, па је
одговарајућа ћелија празна. Ипак, ради прегледности и лакшег одржавања кода,
препоручује се да у сваком реду наведеш све колоне, чак и када неке ћелије
немају податке.

Унутар ћелија, осим стандардног неформатираног текста, можеш слободно користити
линкове, преформатирани текст, стилизован текст и др. У следећем примеру...

``` markdown

| Бр.  | Име       | Презиме     | Сајт                          |
| ---- | --------- | ----------- | ----------------------------- |
| `1`  | **Петар** | *Петровић*  | [pera.com](https://pera.com/) |
| `2`  | **Јован** | *Јовановић* | [jova.com](https://jova.com/) |
| `3`  | **Мира**  | *Мирић*     | [mira.com](https://mira.com/) |
```

...у првој колони подаци су приказани као преформатирани текст, у другој као
задебљан текст, у трећој као укошен текст, а у четвртој као линкови:

| Бр.  | Име       | Презиме     | Сајт                          |
| ---- | --------- | ----------- | ----------------------------- |
| `1`  | **Петар** | *Петровић*  | [pera.com](https://pera.com/) |
| `2`  | **Јован** | *Јовановић* | [jova.com](https://jova.com/) |
| `3`  | **Мира**  | *Мирић*     | [mira.com](https://mira.com/) |

Такође, текст можеш поравнати улево, удесно или по средини колоне тако што ћеш
поставити двотачке `:` са леве, десне или са обе стране цртица у другом реду.
У следећем примеру:

``` markdown

| Бр. | Име   | Презиме     |
| :-- | :---: | ----------: |
| 1   | Петар | Петровић    |
| 2   | Јован | Јовановић   |
| 3   | Мира  | Мирић       |
```

...колона `Бр.` поравната је улево, колона `Име` по средини, а колона `Презиме`
удесно:

| Бр. | Име   | Презиме     |
| :-- | :---: | ----------: |
| 1   | Петар | Петровић    |
| 2   | Јован | Јовановић   |
| 3   | Мира  | Мирић       |

Да би приказао усправну црту `|` унутар ћелије, потребно је да ставиш обрнуту
косу црту `\` испред ње. У следећој табели...

``` markdown

| Усправна црта | Карактер |
| ------------- | -------- |
| Исправно      | \|       |
| Погрешно      | |        |
```

...усправна црта у првом реду приказаће се исправно, док у другом неће. Пошто
усправна црта није означена као обичан текст, парсер ће је протумачити као
раздвајач ћелија. На тај начин настаје додатна ћелија која не одговара заглављу
табеле, па ће њен садржај бити занемарен:

| Усправна црта | Карактер |
| ------------- | -------- |
| Исправно      | \|       |
| Погрешно      |          |

Функционалност рада са табелама у Markdown документима на GitHub-у је свакако
изузетно корисна, али ограничена у односу на стандардне текст едиторе као што
је Microsoft Word. Стандардном Markdown синтаксом није подржано спајање ћелија
по редовима или колонама, нити произвољно подешавање ширине сваке колоне. За
сложене табеле понекад ћеш морати ипак да користиш HTML унутар Markdown
документа јер то GitHub платформа дозвољава.
