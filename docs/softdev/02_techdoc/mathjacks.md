# Рад са математичким формулама

GitHub омогућава да математичке формуле записујеш у LaTeX запису. Тако записане
формуле имају праву математичку нотацију. За имплементацију приказа се користи
MathJax - JavaScript библиотека за приказ математичких израза.

LaTeX је језик за припрему научних радова и техничких докумената. Није потребно
да га учиш у целини - довољно је да савладаш мали скуп команди које ће ти бити
потребан за унос формула у документацији софтверско пројекта.

Формуле унутар текста, тзв. **инлајн формуле**, приказују се као део реченице.
Постоје два начина да њихов означиш почетак и крај. Први начин подразумева да
израз окружиш једним знаком долара `$` са обе стране. На пример, следећи
текст...

``` markdown
Evo formule u rečenici $\sqrt{3x-1}+(1+x)^2$.
```

...приказаће се овако:

Evo formule u rečenici $\sqrt{3x-1}+(1+x)^2$.

Други начин подразумева да израз почиње са знаком долара и обрнутим наводником
<code>&#36;&#96;</code>, а завршава се обрнутим наводником и знаком долара
<code>&#96;&#36;</code>, па ће се тако реченица...

``` markdown
Evo formule u rečenici $`\sqrt{3x-1}+(1+x)^2`$.
```

...приказати исто као и претходна:

Evo formule u rečenici $`\sqrt{3x-1}+(1+x)^2`$.

Други начин је користан када израз садржи знакове који се преклапају са
Markdown синтаксом - на пример доњу цртицу `_` или звездицу `*`. Тада
Markdown парсер може погрешно да протумачи део формуле као истицање текста.
Обрнути наводници спречавају такву грешку.
