# Иницијална подешавања

Пре него што почнеш да користиш Git, добро је да провериш да ли је успешно
инсталиран на твом рачунару. То можеш да урадиш командом:

``` bash
git --version
```

Ако систем врати број верзије (нпр. `git version 2.47.0.windows.1`),
инсталација је била успешна и можеш да наставиш са подешавањима.

## Корисничко име и адреса електронске поште

Прва ствар коју треба да урадиш након инсталације је да подесиш своје
корисничко име и адресу електронске поште. Ови подаци се уписују уз сваки
*commit* који направиш, тако да је важно да их подесиш пре него што почнеш да
радиш на пројекту.

``` bash
git config --global user.name "John Doe"
git config --global user.email johndoe@teslavs.edu.rs
```

Опција `--global` значи да ово подешавање важи за све репозиторијуме твог
корисничког налога на рачунару. Уколико желиш да за одређени пројекат користиш
другачије податке (нпр. другачији мејл за посао, а другачији за личне
пројекте), можеш да изоставиш `--global` и покренеш исту команду унутар тог
репозиторијума. Тада ће подешавање важити само локално, за тај репозиторијум, и
имаће предност у односу на глобално подешавање.

## Едитор текста

Након тога, потребно је да подесиш едитор који ћеш користити. Ако ово не
урадиш, Git ће користити подразумевани текст едитор у оперативном систему
(нпр. *Notepad*).

``` bash
git config --global core.editor "code --wait"
```

Ако у систему није дефинисана путања до Visual Studio Code едитора, јавиће се
грешка. У том случају мораш да наведеш целу путању приликом подешавања
едитора.

``` bash
git config --global core.editor "'C:\Program Files\Microsoft VS Code\Code.exe' --wait"
```

Уколико не користиш Visual Studio Code, можеш да подесиш било који други едитор
на исти начин.

## Подразумевана грана

Када креираш нови репозиторијум, Git ће подразумевано да направи главну грану
под именом `master`. То име можеш да измениш, на пример у `main`.

``` bash
git config --global init.defaultBranch main
```

## Завршеци линија (autocrlf)

Пошто ћеш на пројектима често сарађивати са колегама који раде на различитим
оперативним системима, важно је да подесиш и начин на који Git третира
завршетке линија у текстуалним фајловима - Windows и Linux/macOS их бележе
на различит начин, што може да направи непотребне разлике у фајловима приликом
сарадње. Ако радиш у оперативном систему Windows, препоручено подешавање је:

``` bash
git config --global core.autocrlf true
```

## Провера подешавања

На крају, можеш да провериш сва актуелна подешавања...

``` bash
git config --list
```

...или свако од актуелних појединачних подешавања, на пример, корисничко име:

``` bash
git config user.name
```

Сва ова подешавања се чувају у једном текстуалном фајлу на твом рачунару
(`C:\Users\<корисничко_име>\.gitconfig` у Windows оперативном систему), тако да
их у сваком тренутку можеш отворити и уредити и директно у том фајлу.
